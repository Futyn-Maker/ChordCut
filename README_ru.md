# ChordCut

ChordCut — это портативный музыкальный клиент для [Jellyfin](https://jellyfin.org/) на Windows. Программа воспроизводит все аудиоформаты нативно через MPV без перекодирования на сервере, отображает медиатеку в многоколоночном списке с обложками, поддерживает синхронизированные тексты песен, плей-листы и панель воспроизведения с полным набором элементов управления. Все действия можно выполнить как мышью, так и с клавиатуры; Скринридеры (NVDA, JAWS) поддерживаются из коробки.

## Возможности

- Воспроизведение музыки прямо с сервера Jellyfin без перекодирования — все форматы аудио воспроизводятся нативно через MPV.
- Многоколоночный список медиатеки с обложками, подсветкой под курсором мыши и отметкой играющей композиции. Обложки кешируются локально: загружаются один раз и после этого доступны без сети.
- Просмотр медиатеки по разделам: композиции, исполнители, исполнители альбома, альбомы, плей-листы — с иерархической навигацией.
- Панель воспроизведения со слайдером для перемотки, кнопками управления, переключателями повтора и перемешивания и регулятором громкости.
- Панель текста рядом со списком: синхронизированный текст прокручивается в такт музыке, как в караоке; Клик по строке выполняет переход к ней.
- Отдельные окна для просмотра обычного и синхронизированного текста; в синхронизированном тексте текущая строка подсвечивается по ходу воспроизведения.
- Поиск в реальном времени: список фильтруется по мере ввода.
- Сортировка композиций по алфавиту или дате добавления; фильтрация по медиатекам, если на сервере их несколько.
- Очередь воспроизведения со следующей/предыдущей композицией, повтором и перемешиванием.
- Создание, переименование и удаление плей-листов; добавление и удаление композиций; изменение порядка перетаскиванием мышью, с клавиатуры или через контекстное меню.
- Выбор нескольких композиций для формирования очереди, массового добавления в плей-лист, массового скачивания и других действий.
- Скачивание отдельных композиций или нескольких выбранных сразу в настраиваемую папку.
- Просмотр подробных свойств композиций (битрейт, формат, размер файла), альбомов, исполнителей и плей-листов.
- Копирование ссылки Jellyfin на любой элемент или прямой ссылки потока для композиций.
- Таймер сна с тремя действиями: закрыть программу, выключить компьютер или перевести в спящий режим.
- Иконка в системном трее с базовым управлением воспроизведением — сворачивайте программу и слушайте музыку в фоне.
- Глобальные горячие клавиши, которые работают из любого приложения: воспроизведение/пауза, следующая/предыдущая композиция, перемотка, громкость, повтор, перемешивание, показ и скрытие окна.
- Поддержка мультимедийных клавиш клавиатуры и кнопок Bluetooth-гарнитур через стандартный медиасеанс Windows; в системной панели мультимедиа отображаются название, исполнитель и обложка играющей композиции.
- Подключение к нескольким серверам Jellyfin и переключение между ними.
- Полное управление с клавиатуры и поддержка скринридеров (NVDA, JAWS); интерфейс следует стандартным цветам Windows, поддерживая режимы высокой контрастности.
- Настройка шага громкости и перемотки, выбор устройства вывода; размер и положение окна, громкость и устройство запоминаются между запусками.
- Встроенное автообновление — проверка новых версий при запуске или по запросу с установкой без выхода из программы.
- Полностью портативная: программа запускается из одной папки без установки.

## Начало работы

### Установка

Скачайте архив `ChordCut-Windows.zip` со [страницы последнего релиза](https://github.com/Futyn-Maker/chordcut/releases/latest/download/ChordCut-Windows.zip) и распакуйте его в любую удобную папку. Никакой установки не требуется — просто запустите `ChordCut.exe`.

### Подключение к серверу

При первом запуске ChordCut открывает диалог подключения. Введите адрес сервера Jellyfin (например, `https://demo.jellyfin.org/unstable`), имя пользователя и пароль, затем нажмите «Подключиться». При следующих запусках сохранённые данные используются автоматически.

### Обзор интерфейса

Главное окно состоит из следующих элементов:

- **Раздел** — выбор раздела медиатеки: Композиции, Плей-листы, Исполнители, Исполнители альбома, Альбомы.
- **Поиск** — поле ввода для фильтрации текущего списка в реальном времени.
- **Медиатека** — список элементов текущего раздела в виде таблицы с колонками: обложка, название, исполнитель, альбом, номер, время (набор колонок зависит от раздела; в узком окне второстепенные колонки скрываются). Метка над списком показывает контекстный счётчик (например, «1100 композиций», «5 альбомов Исполнитель»), а играющая композиция отмечается в списке.
- **Панель текста** (по желанию) — отображает текст играющей композиции рядом со списком; по умолчанию скрыта.
- **Устройство вывода** — выбор аудиоустройства для воспроизведения.
- **Панель воспроизведения** — обложка альбома и строка «Сейчас играет», слайдер для перемотки с прошедшим и общим временем, кнопки «перемешать», «предыдущая», «воспроизведение/пауза», «следующая», «повтор», кнопки панели текста и настроек, а также регулятор громкости. При наведении мыши на любой элемент появляется подсказка с горячей клавишей. Включённые переключатели (повтор, перемешивание, панель текста) выделяются акцентным цветом с точкой под значком.

Строка состояния внизу окна показывает текущий статус, время воспроизведения, обратный отсчёт таймера сна (если активен) и уровень громкости. Клавиша Tab перемещает фокус между полем «Раздел», поиском, списком и выбором устройства вывода.

Строка меню содержит четыре меню: **Файл**, **Воспроизведение**, **Вид**, **Справка**.

## Использование

### Навигация по медиатеке

Переключайтесь между разделами в поле «Раздел». Чтобы открыть элемент — альбомы исполнителя, композиции альбома — дважды щёлкните по нему или нажмите Enter. Чтобы вернуться на уровень назад, нажмите Backspace, боковую кнопку «Назад» на мыши (если она есть) или выберите «Назад» в контекстном меню.

Поиск работает по названию для исполнителей и плей-листов, по названию и исполнителю для альбомов, по названию, исполнителю и исполнителю альбома для композиций.

### Воспроизведение

Дважды щёлкните по композиции, нажмите Enter или (когда ничего не воспроизводится) мультимедийную клавишу «воспроизведение/пауза», чтобы начать воспроизведение. При этом автоматически формируется очередь из всех видимых в данный момент композиций. Для перехода к следующей или предыдущей используйте кнопки на панели воспроизведения, Shift+стрелка вправо и Shift+стрелка влево либо мультимедийные клавиши «следующая»/«предыдущая» на клавиатуре. Пауза и продолжение — кнопкой «воспроизведение/пауза», клавишей Escape или мультимедийной клавишей «воспроизведение/пауза».

- **Повтор** (кнопка на панели, меню «Воспроизведение» или Ctrl+Alt+R) — зацикливает текущую композицию. Переход к следующей/предыдущей при этом продолжает работать.
- **Перемешать** (кнопка на панели, меню «Воспроизведение» или Ctrl+Alt+S) — изменяет порядок очереди случайным образом. При отключении исходный порядок восстанавливается.
- **Остановить** (Ctrl+Alt+Q или мультимедийная клавиша «стоп») — полностью останавливает воспроизведение и удаляет очередь.
- **Начать сначала** (Ctrl+Alt+X) — воспроизводит текущую композицию с начала.

### Громкость и перемотка

Щёлкните по полосе перемотки или перетащите её ползунок, чтобы перейти к любому месту композиции; громкость задаётся регулятором на панели. Колёсико мыши тоже работает над панелью воспроизведения: над полосой перемотки оно перематывает, в остальных местах — меняет громкость.

С клавиатуры громкость изменяется сочетаниями Ctrl+стрелка вверх / Ctrl+стрелка вниз, перемотка — Ctrl+стрелка вправо / Ctrl+стрелка влево. Размер шага для клавиш и колёсика настраивается в диалоге «Настройки» (F8); по умолчанию — 5% для громкости и 5 секунд для перемотки.

### Поиск и сортировка

Введите текст в поле поиска, чтобы фильтровать текущий список в реальном времени. Очистите поле, чтобы снова увидеть весь список.

Порядок сортировки раздела «Композиции» задаётся в меню **Вид > Сортировка**:

- По алфавиту А–Я
- По алфавиту Я–А
- По дате добавления (сначала новые)
- По дате добавления (сначала старые)

Для остальных разделов порядок фиксирован: альбомы сортируются по номеру дорожки, плей-листы — по позиции, исполнители — по алфавиту.

Пункт **Вид > Перемешать список** случайным образом перетасовывает текущий список — это удобно, если нужно быстро сформировать случайную очередь.

### Фильтрация по медиатекам

Если на сервере несколько музыкальных медиатек (например, «Музыка» и «Саундтреки»), используйте меню **Вид > Медиатеки**, чтобы включить или отключить нужные. Выбор сохраняется между запусками. Плей-листы отображаются всегда, независимо от фильтра.

### Управление плей-листами

- **Создать**: **Файл > Новый плей-лист...** или Ctrl+N. Введите название в появившемся диалоге.
- **Переименовать**: выберите плей-лист и нажмите F2 или откройте контекстное меню.
- **Удалить**: выберите плей-лист и нажмите Delete или откройте контекстное меню. Подтвердите удаление в диалоге.
- **Добавить композицию**: откройте контекстное меню на любой композиции, выберите «Добавить в плей-лист» и выберите нужный плей-лист в подменю. Композиция добавляется в начало.
- **Удалить из плей-листа**: находясь внутри плей-листа, выберите композицию и нажмите Delete или откройте контекстное меню.
- **Изменить порядок**: внутри плей-листа перетащите композицию мышью на новую позицию, нажмите Alt+стрелка вверх / Alt+стрелка вниз или воспользуйтесь контекстным меню. (Перетаскивание доступно, пока список не отфильтрован поиском и не перемешан — тогда позиции в списке совпадают с позициями в плей-листе.)

### Выбор нескольких композиций

Из любого списка композиций можно выбрать несколько, чтобы сформировать собственную очередь воспроизведения или выполнить массовые действия.

- **Добавить в выбранные**: нажмите пробел на композиции или щёлкните по ней с зажатой клавишей Ctrl. Ctrl+Shift+клик добавляет сразу диапазон композиций. Выбранные композиции отмечаются в списке галочкой; порядок выбора сохраняется. Ctrl+клик по уже выбранной композиции убирает её из выбранных.
- **Область выбранных**: после выбора хотя бы одной композиции между основным списком и полем «Устройство вывода» появляется новая область. В ней отображаются выбранные композиции и количество. Кнопка «Очистить выбор» очищает выбор.
- **Убрать из выбранных**: нажмите пробел (или Ctrl+клик) на композиции внутри списка выбранных. Когда убирается последняя, область исчезает.
- **Воспроизвести выбранное**: дважды щёлкните по композиции в списке выбранных или нажмите Enter — воспроизведение начнётся с этой композиции, а вся подборка станет очередью.
- **Изменить порядок**: внутри списка выбранных перетащите композицию мышью на новую позицию, нажмите Alt+стрелка вверх / Alt+стрелка вниз или воспользуйтесь контекстным меню.
- **Групповые действия** (когда фокус в списке выбранных):
  - Ctrl+Shift+Enter — скачать все выбранные композиции по одной.
  - Ctrl+C — скопировать ссылки Jellyfin на все выбранные композиции (по одной на строку).
  - Ctrl+Shift+C — скопировать прямые ссылки потоков на все выбранные композиции (по одной на строку).
  - Контекстное меню > «Добавить всё в плей-лист» — добавить все выбранные композиции в указанный плей-лист, пропуская уже присутствующие.
  - Контекстное меню > «Удалить всё из плей-листа» — удалить выбранные композиции из текущего плей-листа (доступно только внутри плей-листа).
  - Delete — то же, что «Удалить всё из плей-листа», если это действие доступно.
- **Сохранение**: выбор сохраняется при навигации между разделами. Он сбрасывается только при нажатии «Очистить выбор» или закрытии программы.

> **Примечание.** Когда фокус находится в основном списке, все действия (Enter, контекстное меню, горячие клавиши) применяются к той единственной композиции, на которой стоит курсор — независимо от того, есть ли выбранные.

### Текст песни

**Панель текста** отображает текст играющей композиции рядом со списком. Она включается через меню **Вид > Панель текста**, клавишей F9 или кнопкой на панели воспроизведения; состояние запоминается. Синхронизированный текст движется в такт музыке, как в караоке: текущая строка выделена и удерживается по центру, а клик по любой строке выполняет переход к ней. Прокрутка колёсиком мыши приостанавливает автоматическое слежение на несколько секунд. Обычный текст отображается как прокручиваемый документ.

Текст также открывается в отдельных окнах: нажмите **Ctrl+Alt+Enter** на композиции для обычного текста или **Alt+Shift+Enter** для синхронизированного — оба действия есть и в контекстном меню. В диалоге синхронизированного текста исполняемая строка подсвечивается по ходу воспроизведения; нажмите Enter или дважды щёлкните по любой строке, чтобы перейти к её моменту, а сочетание Ctrl+J или кнопка «Перейти к текущей строке» перемещают к строке, звучащей сейчас. Ctrl+стрелка вверх/вниз и Ctrl+стрелка вправо/влево изменяют громкость и выполняют перемотку так же, как в главном окне. Backspace закрывает диалог, Escape ставит воспроизведение на паузу или возобновляет его. Ctrl+C копирует выделенную строку, кнопка «Копировать всё» — весь текст.

### Скачивание

Нажмите Ctrl+Shift+Enter на композиции или выберите «Скачать» в контекстном меню. Откроется диалог с прогрессом загрузки. Папка для сохранения настраивается в разделе «Настройки» (F8); по умолчанию это вложенная папка `music` рядом с исполняемым файлом.

### Свойства и ссылки

Нажмите Alt+Enter на любом элементе (или выберите «Свойства» в контекстном меню), чтобы открыть его свойства. Для композиций здесь отображаются: название, исполнитель, исполнитель альбома, альбом, продолжительность, номер композиции, формат, битрейт, размер файла и дата добавления. Нажмите Ctrl+C в диалоге свойств, чтобы скопировать выбранное значение.

В основном списке нажмите Ctrl+C, чтобы скопировать ссылку Jellyfin на выбранный элемент, или Ctrl+Shift+C, чтобы скопировать прямую ссылку потока (только для композиций).

### Контекстное меню

Щёлкните по элементу правой кнопкой мыши — или нажмите клавишу Applications или Shift+F10 — чтобы открыть контекстное меню. Правый клик действует на элемент под указателем мыши; клавиатурные варианты — на элемент в фокусе. Доступные действия зависят от типа элемента: воспроизвести, открыть, перейти к исполнителю/альбому, добавить в плей-лист, показать текст, скачать, копировать ссылку, свойства и другие. Внутри плей-листа появляются дополнительные пункты для удаления и изменения порядка.

### Таймер сна

Откройте **Файл > Таймер сна...**. Задайте часы, минуты и секунды, выберите действие («Закрыть программу», «Выключить компьютер» или «Перевести компьютер в спящий режим») и нажмите «Включить таймер». Обратный отсчёт отображается в строке состояния. Чтобы отменить таймер, нажмите на этот же пункт меню повторно.

### Фоновое прослушивание

ChordCut сделан так, чтобы музыка продолжала играть, пока вы работаете в других приложениях. Для этого есть два механизма:

**Глобальные горячие клавиши.** Набор системных сочетаний с модификаторами Ctrl+Shift+Alt работает независимо от того, какое приложение находится в фокусе — даже когда ChordCut скрыт в трее. Полный список — в таблице [Горячие клавиши](#горячие-клавиши) ниже; левые и правые клавиши-модификаторы равнозначны. Сочетания подобраны так, чтобы не конфликтовать ни с командами скринридеров (навигация по таблицам в NVDA и JAWS живёт на Ctrl+Alt), ни с типографскими раскладками на основе AltGr, ни с распространёнными сочетаниями других программ. Если какое-то сочетание уже занято другой программой, ChordCut просто пропускает его и показывает как недоступное во встроенной справке по горячим клавишам (F1) — он никогда не забирает сочетание у работающей программы. Глобальные горячие клавиши можно полностью отключить в настройках.

**Мультимедийные клавиши.** Аппаратные мультимедийные клавиши клавиатуры (воспроизведение/пауза, следующая, предыдущая, стоп) и кнопки Bluetooth-гарнитур управляют ChordCut через стандартный медиасеанс Windows. Какому из запущенных плееров передать нажатие, решает сама Windows — обычно тому, который играл последним, — поэтому ChordCut не конфликтует с другими приложениями за эти клавиши. В системной панели мультимедиа отображаются название, исполнитель, альбом и обложка играющей композиции; её кнопки, полоса перемотки и переключатели перемешивания и повтора управляют ChordCut напрямую.

### Системный трей

Чтобы скрыть ChordCut в область уведомлений и продолжить слушать музыку, выберите **Файл > Свернуть в трей**, нажмите Ctrl+Shift+Alt+C или щёлкните по значку в трее. По умолчанию кнопка закрытия и Alt+F4 тоже сворачивают окно в трей, а не завершают программу (это можно отключить в настройках); для выхода используйте **Файл > Выход** или пункт «Выход» в меню трея.

Клик по значку трея, повторное нажатие Ctrl+Shift+Alt+C (оно работает глобально как переключатель «показать/скрыть») или пункт «Развернуть» в контекстном меню значка возвращают главное окно. Подсказка значка показывает название играющей композиции, а контекстное меню предоставляет базовое управление воспроизведением: пауза/продолжить, следующая/предыдущая, громче/тише, перемотка вперёд/назад, повтор и перемешивание.

### Использование нескольких серверов

Добавляйте серверы через **Файл > Сменить сервер > Управление серверами...**. В диалоге используйте «Добавить...» для нового сервера, «Изменить...» для обновления данных и «Удалить» для удаления (единственный сервер удалить нельзя); активный сервер отмечен в списке. Переключение между серверами — через подменю **Файл > Сменить сервер**.

### Настройки

Нажмите F8, откройте **Файл > Настройки...** или щёлкните по кнопке с шестерёнкой на панели воспроизведения. Доступные параметры:

- **Папка для загрузок** — папка, в которую сохраняются скачанные композиции.
- **Шаг громкости для клавиш и колёсика мыши (%)** — на сколько процентов меняется громкость за одно нажатие горячей клавиши или колёсика (от 1 до 20, по умолчанию 5).
- **Шаг перемотки для клавиш и колёсика мыши (в секундах)** — на сколько секунд выполняется перемотка за одно нажатие горячей клавиши или колёсика (от 1 до 60, по умолчанию 5).
- **Запоминать громкость при выходе** — при следующем запуске восстанавливать последний уровень громкости.
- **Запоминать устройство вывода при выходе** — при следующем запуске восстанавливать последнее выбранное аудиоустройство.
- **Кнопка закрытия сворачивает в трей вместо выхода** — если включено (по умолчанию), кнопка закрытия и Alt+F4 сворачивают программу в трей. Для выхода используйте **Файл > Выход** или меню трея.
- **Глобальные горячие клавиши** — если включено (по умолчанию), системные сочетания работают из любого приложения. См. раздел [Фоновое прослушивание](#фоновое-прослушивание).
- **Проверять обновления при запуске** — если включено (по умолчанию), программа автоматически проверяет наличие новой версии при каждом запуске. При обнаружении обновления предлагается загрузить и установить его. Ручная проверка доступна через **Справка > Проверить обновления...**.

### Обновление программы

Если при запуске найдена новая версия, откроется диалог с описанием изменений. Нажмите «Да», чтобы начать загрузку и установку обновления — программа выполнит всё автоматически и перезапустится. Ручная проверка: **Справка > Проверить обновления...**.
